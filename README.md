# Sistema para Rotas Seguras de Locomoção Urbana

---

Este projeto consiste em uma aplicação desktop que **sugere rotas seguras para locomoção urbana**, promovendo mobilidade sustentável. A solução busca atender ao **Objetivo de Desenvolvimento Sustentável (ODS) 11 - Cidades e Comunidades Sustentáveis**, incentivando deslocamentos a pé, de bicicleta, patinete ou patins, com foco em segurança e qualidade de vida.

## Funcionalidades

* **Avaliação comunitária**: Usuários podem avaliar trechos de ruas com base em segurança, iluminação e condições de tráfego.
* **Sugestão de rotas seguras**: O sistema utiliza as avaliações para recomendar o caminho mais seguro.
* **Comentários e sugestões**: Permite que usuários deixem feedbacks e proponham melhorias para os trechos avaliados.
* **Planejamento futuro**: Integração com câmeras de segurança para alertas em tempo real (em desenvolvimento).
